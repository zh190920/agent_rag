# 引用书写与措辞规范（report-writer 随附参考）

本文件是 `report-writer` 技能的**支撑资源**，用于演示「一个技能目录可附带参考
文件」。技能正文里用相对路径 `${SKILL_DIR}/references/output-checklist.md` 指向
它；模型判断需要更细的引用规范时，用 `read_file` 按需读取（渐进披露，不常驻上下文）。

## 引用格式

- 行级：`文件名.md:42`（第 42 行）
- 区间：`文件名.md:10-18`（读到的连续片段）
- 跨文件对比：每条论据各标各的，不要合并成一条模糊引用

## 措辞要求

| 情形 | 写法 |
|---|---|
| 原文直接支撑 | 陈述结论 + `（文件名:行号）` |
| 由多段推断 | 标注「综合」并列出全部来源行号 |
| 证据不足 | 明确写「未找到原文依据」，**不得臆测** |
| 原文含不确定词 | 保留限定语气（"可能/计划"），不要拔高为确定结论 |

## 反例（禁止）

- ❌ 给出一个原文里根本不存在的行号
- ❌ 只写"据文档可知"却不落到具体 `文件:行号`
- ❌ 把 `grep` 命中的一行断章取义成整段结论（应 `read_file` 读全上下文）

## 交付前自检清单

1. 每条 `文件:行号` 都能在 `read_file` 输出里逐字对上；
2. 「结论」部分没有任何未被论据支撑的新说法；
3. 「待核实 / 局限」如实反映证据边界；
4. 全程只读了授权目录内的文件。
